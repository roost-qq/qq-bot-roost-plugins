# 0.4.2 发布说明与验证范围

记录日期：2026-11-28。版本 `0.4.2`，宿主 Roost 1.1.17。本文件记录发布前的用户验收、日志核对和离线回归。小黑盒私信已完成实验与用户真机验收，本次转为正式能力。市场候选副本的最终门禁与回归结果另附在提交包的验证材料中。

## 用户确认

用户于 2026-11-28 明确确认真机人工验收完成。此前用户也确认 B 站文字群投递可用、重复扫描仍仅一条、重载后没有重复。用户确认属于整体验收结论；下文分项证据用于说明可复核范围，不把整体验收写成尚待验收。

## 独立日志确认

独立本地日志审查确认以下事实：

- 真实小黑盒二维码申请和轮询返回 HTTP 200。
- 账号校验返回 HTTP 200。
- 凭据保存为 accepted。
- 会话／消息读取返回 HTTP 200。
- 一次内置测试通知投递为 `delivery`／`send`／`sent`，`hostSent: true`、`sent: 1`。

内置测试通知只证明测试通知通道可用，不是新私信正文端到端转发的独立证据；不得据此推断双账号收发或完整分页。

## 未逐项独立证实

多次基线结果仍为 `XHH_WATCHING_LIMITED`、`baselineComplete: false`。因此完整分页、历史恢复、未读副作用、图片／分享子能力、风控恢复等没有逐项独立实测记录，记为未逐项独立证实。这不否定用户已确认的整体人工验收，也不要求用户重做已确认项目。

小黑盒继续默认关闭，但能力声明已转为 `verified: true`，不再输出 `experimental` 标记，页面和命令不再显示验收状态文案。完整分页、历史恢复和未读副作用等未逐项证实的边界仍按事实保留。

## 修复保留

`0.4.2` 修正已确认的小黑盒扫码签名端口缺陷：JS 实现遗漏 Python 参考 `_mix_columns` 保留的最后两个未变换校验字节；独立固定参考向量确认旧值为 `SPSPW16 / IZITX58 / VV10Y48`，正确值为 `SPSPW24 / IZITX11 / VV10Y50`。冷却／预算分类修复保留：本地冷却或预算阻止二维码请求时报告 `XHH_COOLDOWN`／`XHH_BUDGET` 和剩余等待，不再误报 `XHH_TIMEOUT`。传输保持 `0.4.1` 的可选 Electron `net` 或 `node:https`、固定 HTTPS GET、无自动重定向／换通道、15 秒总截止。
